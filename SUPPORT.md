# Getting help with Keyway

Thanks for using Keyway. Here's the fastest way to get what you need.

| I want to… | Go to |
|---|---|
| **Ask a question / get usage help** | [GitHub Discussions → Q&A](https://github.com/nometria/keyway/discussions/categories/q-a) |
| **Report a bug** | [Open an issue](https://github.com/nometria/keyway/issues/new?template=bug_report.md) |
| **Request a feature** | [Open an issue](https://github.com/nometria/keyway/issues/new?template=feature_request.md) |
| **Share an idea / show what you built** | [Discussions → Ideas / Show and tell](https://github.com/nometria/keyway/discussions) |
| **Report a security vulnerability** | **Do not open a public issue** — follow [SECURITY.md](SECURITY.md) |
| **Understand the design** | [ARCHITECTURE.md](ARCHITECTURE.md) |
| **Try it in one command** | `make demo` (see the [README quickstart](README.md#quickstart)) |

## Before you post

- Search [existing issues](https://github.com/nometria/keyway/issues?q=is%3Aissue) and
  [discussions](https://github.com/nometria/keyway/discussions) first — your question may already be answered.
- For bugs, include your Keyway version (`keyway version`), how you ran it (Docker / binary / `make demo`),
  and the exact command + output.

Keyway is maintained by volunteers on a best-effort basis — there is no paid support tier or SLA. The more
context you give, the faster someone can help.
